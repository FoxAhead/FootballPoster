A Python tool that transforms match schedules into high-resolution, print-ready calendar posters. Designed for football fans, it creates an visual grid to track scores and group standings throughout a championship.

Match data is based on the Excel tournament schedules provided by [Hermann Baum](https://hermann-baum.de/excel/WorldCup/en/).

Downloads: Ready-to-print posters for various languages and timezones are available in the Releases section.
